# AI Investment Advisor (FinTech Trading AI)

A quantitative strategy and asset management enhancement tool tailored for non-professional retail investors. Built on a lightweight architecture, this project supports real-time multi-stock data fetching, quantitative indicator calculations (MACD, Sharpe Ratio, P/E ratio), interactive visualisation, a SQLite local persistent database, and professional investment advisory analysis reports generated by LLM. The entire system supports a **bilingual (Chinese/English) interface**, switchable instantly with one click in the sidebar.

---

## 🌟 Three Features: Planning & In-Depth Evaluation

### 1. Portfolio Analytics & Sharpe Ratio
* **Pain Point**: Non-professional investors tend to pile into a single popular stock, making it difficult to assess the overall value-for-money of their portfolio and non-systematic risk.
* **Technical Solution**: Introduces covariance matrix calculations across multiple stocks' historical returns, dynamically computing the portfolio's expected annualised return, annualised volatility, and Sharpe Ratio (Sharpe Ratio = (Rp − Rf) / σp) based on custom weights.
* **Effectiveness**: Intuitively demonstrates how diversification exploits low correlations between assets to reduce overall portfolio variance, raising retail investors' risk awareness.

### 2. Multi-Dimensional Strategy: MACD Momentum + P/E Valuation Percentile
* **Pain Point**: Relying solely on MACD makes it easy to chase highs during low-volume consolidation or high-valuation bubbles; relying solely on P/E risks falling into long-term "value traps".
* **Technical Solution**: Fuses technical indicators (MACD golden cross/death cross, Histogram dynamics) with fundamental valuation metrics (Trailing/Forward P/E Ratio), producing four weighted conclusions (Strong Buy, Speculative Buy, Accumulate, Reduce/Watch).
* **Effectiveness**: Significantly reduces the probability of triggering false breakout signals, providing retail investors with technical signals that carry a margin of safety.

### 3. LLM Intelligent Advisory Reports & SQLite Database Integration
* **Pain Point**: Complex quantitative data presents a barrier to retail investors, while there is a lack of simple mechanisms for reviewing positions and trade motivations.
* **Technical Solution**:
  - **LLM Integration**: Supports user-supplied custom OpenAI API Keys. If no Key is provided, the system also includes a professional-grade heuristic financial rules interpretation engine (Fallback Heuristic Engine), guaranteeing plain-language analysis in a Hong Kong financial context with zero configuration. A built-in 4-second timeout guard and automatic interception of proxy server anomalies ensure the system never hangs.
  - **SQLite Integration**: Creates a local relational database `trading_app.db`, containing position management (`portfolio`) and strategy simulation logs (`trade_history`).
* **Effectiveness**: Makes decisions well-grounded and evidence-based, improving long-term investment discipline for non-professional users.

## 🚀 Quick Start Guide

### 1. Install Dependencies

Recommended to run in a Python 3.10+ virtual environment:

    # Create and activate a virtual environment (optional but recommended)
    python -m venv venv
    source venv/bin/activate        # macOS / Linux
    # venv\Scripts\activate         # Windows

    # Install all dependencies
    pip install -r requirements.txt

Key dependencies (see `requirements.txt` for details):
* `streamlit` — Interactive web interface framework
* `yfinance` — Real-time stock historical data and fundamental information fetching
* `pandas` / `numpy` — Data processing and quantitative calculation core
* `plotly` — Professional interactive candlestick charts, MACD subplots, and cumulative NAV trend charts
* `openai` — LLM intelligent advisory report generation (optional; works fine without a Key)
* `requests` — Basic network request support

### 2. Launch the Application

Enter the following command in the Terminal / CMD (note: this is a command-line command, not a filename):

    streamlit run app.py

Once running, the browser will automatically open http://localhost:8501 and you can start using the app.

### 3. First Use

On first launch, the system automatically calls `database.init_db()` to create the `trading_app.db` SQLite database file in the project root directory — no manual setup or migration scripts required.

### 4. Interface Language Switching

In the "🌐 Language / 語言" option at the top of the sidebar, choose **中文 (繁體)** or **English** to instantly switch the entire application interface, including:

* All tab titles, buttons, forms, and prompt messages
* Strategy signals and valuation assessment text (strategies.py output)
* Language of advisory reports generated by the LLM / expert rules engine (llm_analyst.py)
* Chart titles and axis labels

## 📊 Feature Modules in Detail

### A. Individual Stock Strategy Analysis (strategies.py)

* Supports fuzzy search by full or partial company name and ticker, showing the closest Yahoo Finance matches for the user to select.

| Function | Description |
|------|----------|
| `fetch_stock_data(ticker, period)` | Fetches historical OHLCV price data for the specified period (6mo / 1y / 2y / 5y) via `yfinance` |
| `fetch_fundamental_info(ticker)` | Fetches fundamental information (Trailing P/E, Forward P/E, market cap, currency, industry sector, etc.) |
| `calculate_macd(df)` | Calculates the MACD line (EMA12 - EMA26), signal line (EMA9), and Histogram values |
| `generate_signals(df, fundamental, language)` | Fuses technical and fundamental analysis to output weighted trading signals and an overall conclusion (supports Chinese / English bilingual text) |
| `calculate_portfolio_metrics(...)` | Calculates portfolio annualised return, volatility, Sharpe Ratio, and per-stock comparison metrics |

**Signal Interpretation Logic (Four Overall Conclusions):**
1. **STRONG BUY** — MACD golden cross + P/E in a reasonably low range (momentum and valuation both supportive)
2. **SPECULATIVE BUY** — MACD golden cross but valuation on the high side (strong short-term momentum, insufficient margin of safety)
3. **ACCUMULATE** — Cheap valuation but technicals not yet turned strong (defensive low-valuation strategy)
4. **SELL** — MACD death cross, technical indicators weakening

**P/E Valuation Grading Standards:**
* P/E < 15 → Attractive valuation (value-type target)
* 15 ≤ P/E ≤ 30 → Reasonable growth range
* P/E > 30 → Valuation on the high side; watch for the risk of growth expectations failing to materialise
* P/E unavailable or negative → Possibly in a loss-making state

### B. Portfolio & Sharpe Ratio (Tab 2)

* Enter multiple stock tickers (comma-separated) and custom weights; the system automatically:
  1. Downloads the past year of historical closing prices and calculates daily returns;
  2. Annualises over 252 trading days to compute the portfolio's expected annualised return;
  3. Builds the covariance matrix to derive the portfolio's annualised volatility;
  4. Calculates the Sharpe Ratio: (portfolio annualised return − risk-free rate) / portfolio volatility.
* Also outputs a **per-stock** comparison table of annualised return, volatility, and Sharpe Ratio, making it easy to identify which stock is dragging down portfolio performance.
* Includes a **historical cumulative NAV trend chart** (base = 1.0) for intuitive comparison of asset performance.

> 💡 Sharpe Ratio reference: > 1 is good, > 2 is excellent, and a negative value means performance worse than the risk-free rate.

### C. Position Management & Trade Log (database.py)

| Function | Description |
|------|----------|
| `init_db()` | Initialises the database, creating the `portfolio` and `trade_history` tables |
| `add_position(ticker, shares, cost_price)` | Adds a position record |
| `get_portfolio()` | Reads all positions as a DataFrame |
| `delete_position(position_id)` | Deletes a specified position by ID |
| `record_trade(ticker, action, shares, price, strategy_signal)` | Records a simulated trade and the strategy signal that triggered it (for later review) |
| `get_trade_history()` | Reads the full trade history log in reverse chronological order |

**Database Schema:**

    -- Positions table
    CREATE TABLE IF NOT EXISTS portfolio (
        id INTEGER PRIMARY KEY AUTOINCREMENT,
        ticker TEXT NOT NULL,
        shares REAL NOT NULL,
        cost_price REAL NOT NULL,
        created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
    );

    -- Trade history table
    CREATE TABLE IF NOT EXISTS trade_history (
        id INTEGER PRIMARY KEY AUTOINCREMENT,
        ticker TEXT NOT NULL,
        action TEXT NOT NULL,          -- BUY / SELL
        shares REAL NOT NULL,
        price REAL NOT NULL,
        strategy_signal TEXT,          -- Strategy signal / trade motivation at the time of execution
        executed_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
    );

### D. LLM Intelligent Advisory Report (llm_analyst.py)

| Function | Description |
|------|----------|
| `generate_ai_analysis(ticker, signals, fundamental, openai_api_key, language)` | Calls the OpenAI API (gpt-3.5-turbo) to generate a professional plain-language analysis report (language follows the interface setting) |
| `fallback_heuristic_analysis(ticker, signals, fundamental, language)` | Heuristic rules engine used when no API Key is available; generates Hong Kong-context interpretation based on quantitative signals (bilingual) |

**Workflow & Defensive Mechanisms:**
1. Users can enter a custom OpenAI API Key in the sidebar (stored only in the session, never written to the database).
2. If the Key format is valid (starts with `sk-`) → calls the LLM to generate personalised in-depth analysis.
3. If no Key or invalid format → directly uses the local heuristic rules engine, issuing no network requests.
4. If the API fails (timeout / proxy server error / invalid HTML response) → automatically intercepts and switches to the Fallback engine, ensuring reports are never interrupted.
5. Built-in **4-second hard timeout** and **zero retries** settings (`timeout=4.0`, `max_retries=0`) to completely prevent connection hangs.
6. Report language automatically follows the interface language setting in the sidebar (Chinese / English).

**Report Content Structure (LLM Version):**
1. Technical and momentum analysis (interpreting MACD signals and divergences)
2. Fundamental valuation judgement (analysing whether the P/E ratio is reasonable)
3. Concrete action strategy (buy, wait, or stop-loss level suggestions)
4. Risk warnings tailored to individual investors

## 💡 Suggested Usage Flow

1. **Stock Diagnosis**: In the "Individual Stock Technical & Valuation Strategy" tab, enter a stock ticker (e.g. `AAPL`, `MSFT`, `0700.HK`), choose the analysis period, and run the AI diagnosis to view the candlestick chart, MACD subplot, and overall signal.
2. **Portfolio Health Check**: In the "Portfolio Analysis" tab, enter multiple holdings and weights, set the risk-free rate, and review the Sharpe Ratio and cumulative NAV trend to evaluate diversification effectiveness.
3. **Record Positions**: In the "Position Management" tab, write your actual holdings (share count, cost price) into the SQLite database to build your personal position list.
4. **Simulated Trade Review**: Record the strategy signal and motivation for each simulated buy/sell; later review decision quality via the trade history log to build investment discipline.
5. **Make Good Use of AI Reports**: Enable LLM in-depth analysis when you have an API Key; without a Key, the heuristic engine still provides basic interpretation.
6. **Bilingual Interface**: In the "🌐 Language / 語言" option at the top of the sidebar, switch between Chinese / English with one click — all tabs, signals, reports, and chart text switch instantly in sync.
